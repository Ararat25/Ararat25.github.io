# Портфолио Арарата Ваняна

Статический одностраничный сайт для GitHub Pages. Содержимое проектов и достижений хранится отдельно от разметки, поэтому обновлять его можно прямо в браузере на GitHub.

## Как добавить или удалить достижение

1. Откройте файл `data/achievements.json` в репозитории.
2. Нажмите значок карандаша, чтобы редактировать файл.
3. Чтобы добавить достижение, скопируйте один объект между фигурными скобками и заполните поля `year`, `category`, `categoryLabel`, `title` и `detail`. Разделяйте соседние объекты запятой.
4. Чтобы убрать запись, удалите объект целиком и проверьте запятую у соседней записи.
5. Нажмите **Commit changes**. GitHub Pages обновит сайт автоматически после завершения публикации.

Допустимые значения `category` — `award`, `research` и `learning`. Они отображаются в соответствующих фильтрах на сайте. Заголовок и описание обычные строки JSON; внутренние кавычки в тексте нужно экранировать обратной косой чертой `\\"`.

У записи может быть поле `url` со ссылкой на статью или источник: если оно заполнено, заголовок на сайте становится кликабельным (пунктирное подчёркивание и стрелка ↗), ссылка открывается в новой вкладке. Пустое поле или его отсутствие оставляет заголовок обычным текстом. Пример: `"url": "https://elibrary.ru/..."`.

Пример новой записи:

```json
{
  "year": "2026",
  "category": "award",
  "categoryLabel": "Награда",
  "title": "Название достижения",
  "detail": "Организация или краткое пояснение.",
  "url": "https://example.com/source"
}
```

## Как обновить проект

Аналогичным способом отредактируйте `data/projects.json`. У проекта есть `title`, `kind`, `description`, `role`, `stack`, `url` и `featured`. Для репозитория указывайте полный URL `https://github.com/...`; чтобы карточка была без внешней ссылки, оставьте `url` пустой строкой. Не меняйте структуру HTML и JavaScript для обычного редактирования контента.

## Проверка изменений

Перед коммитом проверьте запятые и двойные кавычки в JSON. Если сайт не показывает обновлённое содержимое сразу после публикации, подождите завершения GitHub Pages deployment и обновите страницу без кэша.

## Публикация

Для личного сайта GitHub Pages используются источник **Deploy from a branch**, ветка `main` и папка `/(root)`. После включения Pages основной адрес будет `https://Ararat25.github.io/`. Исходники репозитория публичны, поэтому не добавляйте сюда секреты, личные документы или данные, которые не должны быть видны всем.
